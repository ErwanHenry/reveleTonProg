<interfaces>
Dispatcher contract (consumed by 08-06 workflows, 08-03 installer, 08-10/08-13/08-15 server plans). Installed path `/usr/local/sbin/rtp-deploy-command`, run by sshd as user `deploy` through `restrict,command="/usr/local/sbin/rtp-deploy-command"`. Input only `SSH_ORIGINAL_COMMAND`.
- Layout: `BASE=${RTP_BASE:-/srv/reveletonprog}`; cible `production` -> racine `$BASE`; cible `essai` -> racine `$BASE/essai`; each racine has `releases/<40hex>/`, a relative link `current -> releases/<sha>`, an append-only `.historique` (lines `<ISO8601 UTC> <sha>`); uploads land in `$BASE/incoming/<cible>/<sha>/`; lock file `$BASE/.verrou`.
- Verbs and one-line outputs:
  - `rsync --server … <cible>/<sha>/` -> disk guard, `mkdir -p $BASE/incoming/<cible>`, `exec "$RRSYNC" -wo -no-del "$BASE/incoming"` (rrsync re-reads SSH_ORIGINAL_COMMAND)
  - `activer <cible> <sha>` -> `active cible=<cible> courant=<sha> versions=<n>`
  - `retour <cible> [<sha>]` -> `retour cible=<cible> courant=<sha> precedent=<sha>`
  - `etat <cible>` -> `etat cible=<cible> courant=<basename or aucun> versions=<n> libre_mio=<n>`
- Exit codes: 0 ok, 64 refused (charset, verb, token, arity), 65 upload invalid (missing index.html or version.json commit mismatch), 66 release not found, 75 not enough disk (free < 1024 MiB or use >= 92 %), 1 other failure.
Facts from 08-RESEARCH « Pattern 2 » (a) to (i) apply as written: relative target, `mv -T` fails closed on a real directory, history drives previous, rotation deletes only 40-hex names and never current or previous, flock -w 20 around activer and retour, stale `incoming/*/*` older than one day removed at each call.
Live server facts: Caddyfile `/opt/vaultwarden/Caddyfile` (single-file bind mount, 15 site blocks, no global block), container `caddy`, image id read with `docker inspect caddy --format '{{.Image}}'`, `docker exec caddy caddy version` = v2.11.2, rrsync at `/usr/bin/rrsync`, jq present, GNU coreutils, util-linux flock.
</interfaces>
