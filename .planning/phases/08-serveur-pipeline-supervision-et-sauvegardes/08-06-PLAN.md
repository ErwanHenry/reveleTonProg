## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pull request / fork to secrets | Untrusted code must never reach the Environment secrets |
| GitHub runner to VPS | Deploy key and host pin cross into the shared server |
| approval to stale commit | Erwan may approve a run after main moved |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-28 | Elevation of privilege | secrets exposed to PR code | mitigate | no pull_request_target; deploy, retour and sonde jobs only on main/dispatch/schedule with Environments limited to main; secrets only in their step env (test) |
| T-08-29 | Spoofing | MITM on SSH | mitigate | known_hosts line from an Environment variable, StrictHostKeyChecking=yes, no keyscan (test) |
| T-08-30 | Tampering | unreviewed or stale deploy | mitigate | Environment required reviewer, main-head check, freeze gate, concurrency without cancel |
| T-08-31 | Information disclosure | preview or draft content shipped | mitigate | no RTP_MODE in deploy, no download-artifact, check-dist --mode production (test) |
| T-08-32 | Elevation of privilege | production built without the deployment guard | mitigate | exact RTP_DEPLOIEMENT expression on build and check-dist, production => 1 (test) |
| T-08-33 | Information disclosure | key left on the runner, secrets in argv | mitigate | umask 077 files in RUNNER_TEMP removed in always(); credentials through curl --config - fed by printf builtin |
| T-08-34 | Tampering | workflow command injection through the justification | mitigate | newline stripping and 300-character limit in garde-gel before printing |
| T-08-35 | Denial of service | false alert from a single probe failure | mitigate | no /fail; Healthchecks period plus grace gives about 3 missed probes |
| T-08-36 | Denial of service | approval wait blocks or cancels later CI runs | mitigate | per-run workflow concurrency group on main |
</threat_model>
