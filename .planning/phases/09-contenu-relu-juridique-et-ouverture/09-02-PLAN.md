**Design decisions of this plan (research left them open):**
- The whitelist is read from the **content root** (`<racine de contenu>/config/publication.yml`), not from the project root: it is an editorial decision attached to a corpus, and the fixtures need their own list. For the real corpus the content root is the project root, so the file is `config/publication.yml`. A missing file equals an empty list.
- Severities are asymmetric. Dangerous direction (published but not opened): error in production. Safe direction (opened but not published, or nothing open): warning, so that the fallback « repasser le thème en brouillon » of the emergency withdrawal (research resolution, 09-06) never blocks a deploy. The check « at least one open theme » is a gate of the go-live plan (09-12), not a build error.
- `config/publication.yml` is created with an empty list. Adding `sante` is the explicit decision of the publication commit (09-11), reviewed by Erwan.
