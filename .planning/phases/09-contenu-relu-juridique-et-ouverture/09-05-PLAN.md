    - `servir [--theme <id>] [--port <n>]` (default theme `sante`, default port 4327): creates the server, listens with `server.listen(port, '127.0.0.1')`, checks `server.address().address` is `127.0.0.1` (else closes and exits 1), prints `http://127.0.0.1:<port>/` and « Ctrl+C pour arrêter » ; exits 1 if the port is taken
    - Routes: `GET /` (summary table per candidate, totals « reste N sur M », link to each candidate); `GET /candidat/<id>` (the sheet: status block, coverage block, one block per measure with the four wordings in a grid next to the source text and the extract window with the quote in `<mark>`, sources, alerts, open notes, and the two forms); `POST /valider` (fields `type` in mesure|statut|case, `cible`, `jeton`) calls the `marquer` core with the default reviewer and today's date; `POST /note` (fields `cible`, `texte`, `jeton`) adds a note; both answer 303 to the candidate page with a short status message in the query string taken from a closed list of codes; any other path or method: 404 or 405

## Trust Boundaries

|----------|-------------|
| any web page in Erwan's browser to 127.0.0.1 | A hostile page can send requests to a local port |
| third-party text (wordings, quotes, archives) to the review page | Untrusted strings rendered as HTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-23 | Tampering | CSRF: a third-party page posts « valider » to the local server | mitigate | per-launch random token compared in constant time, Origin and Sec-Fetch-Site checks, form content type only |
| T-09-24 | Spoofing | DNS rebinding to 127.0.0.1 | mitigate | exact Host check (421), loopback bind verified after listen |
| T-09-25 | Tampering | stored XSS from wordings, quotes or notes | mitigate | one escaping function for every string, CSP `default-src 'none'`, no script element |
| T-09-26 | Tampering | path traversal through a forged target | mitigate | identifiers only, regex then resolution in the loaded list; archive read through `readContained` |
| T-09-27 | Denial of service | oversized POST body | mitigate | 8 Kio cap (413) |
| T-09-28 | Information disclosure | review tool shipped with the public site | mitigate | repo test on references from src/ and astro.config.mjs; check-dist file-type allowlist already refuses foreign files |
| T-09-29 | Elevation of privilege | another local user or process reaching the port | accept | single-user Mac, loopback only, token required for any write |
</threat_model>
