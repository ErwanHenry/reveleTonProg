<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| command line to src/content | A local tool writes into the published corpus |
| YAML text from third-party sites to the tool | Wording and quotes are untrusted data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | editer.ts rewriting wording or reformatting a file | mitigate | closed list of writable keys, splice at node offsets, `verifierSeulesCles` (parsed equality minus the keys, bounded line diff), proof on every real file |
| T-09-02 | Tampering | forged target identifier reaching another file | mitigate | strict identifier regex, resolution in the `loadAll` list, `ecrireAtomique` containment under src/content, symlinks refused |
| T-09-03 | Tampering | value needing YAML quoting or injecting keys (reviewer name, date) | mitigate | value regexes before any write, plain scalars only |
| T-09-04 | Repudiation | a text changed after its review stays marked relu | mitigate | content hash in relecture/journal.jsonl, state `a_revoir` in `liste` |
| T-09-05 | Elevation of privilege | review status set on a file that fails validation | mitigate | `loadAll` before and after, restore on any new error |
| T-09-06 | Information disclosure | personal data typed in a note of a public repository | accept | README warning, 500-character cap; Erwan is the only writer |
</threat_model>
