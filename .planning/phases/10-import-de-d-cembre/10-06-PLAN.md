**Content rule:** in `src/content/**` only the review tool writes during this plan, and only when the owner runs it or clicks in the review page served from `../reveleTonProg-import` (`npm run relecture -- servir`); a coverage case state, a wording or a status value is never chosen by an agent: a case is written by the owner, or by the orchestrator applying a diff he validated word for word. All these writes happen on branch `import/statuts-2026-12`. Never touch `archives/**`.

**Approvals:** the merge is the owner's (he merges in GitHub, or writes « fusionner » and the orchestrator merges with a merge commit). In both cases the merge happens only after the orchestrator has shown him, for the exact head sha of the pull request, that `git merge-base --is-ancestor origin/main <sha>` is true, that the CI of that sha is green and that validate gives 0 error (and 0 STATUT_PLUS_RECENT_NON_RELU under B); the orchestrator merges with `gh pr merge --merge --match-head-commit <sha>`, and the owner merges in GitHub only the head he was shown. The deploy run of main waits for approval: the owner approves it himself in the GitHub interface (« Review deployments »); the orchestrator never calls the approvals API and rejects only on his instruction; a run is never left pending, and a run still waiting at the freeze start is rejected on his instruction.

**Merge-order rule:** if origin/main moved since the branch was created, the branch is recreated from origin/main and the import rerun as written in the RUNBOOK « Import de décembre » (restore the snapshot and its meta from the old branch, rerun with `--file`, cherry-pick the table commit, the hand-update commit and the owner's review commits; any conflict stops and is shown to him); it is never merged with main. Cutoff: no recreation after the cutoff recorded in 10-04 (default Sunday 13 December 2026, 12:00 Paris); past it, the import is postponed until after the freeze and the pull request stays open.

**Text rule:** hand-written French (commit messages, comments on the pull request) has no em or en dash and none of the forbidden words.
