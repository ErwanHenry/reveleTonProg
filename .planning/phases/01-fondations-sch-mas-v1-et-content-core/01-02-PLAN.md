## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-08 | Tampering | `archive.extrait` path (common def used by source.schema.json) | mitigate | pattern `^archives/([a-z0-9-]+/)*[a-z0-9._-]+\.txt$` forbids `..` segments, absolute paths and non-.txt files; negative cases in source.test (Phase 2 additionally resolves under `archives/` and checks `startsWith`) |
| T-01-09 | Spoofing (misinformation) | measure backed by press or unsourced text | mitigate | `source.type` enum has no `presse`; `source` and `texte_source` required; archive block required on every source |
| T-01-10 | Spoofing / XSS | source URLs | mitigate | `https-url` format; `wayback_url` restricted to `https://web.archive.org/web/<14 digits>/` |
| T-01-11 | Repudiation | fixture content mistaken for real candidate data | mitigate | all fixture URLs on `.invalid` hosts, « fictif » in titles, archive first line `PROGRAMME FICTIF` |
| T-01-12 | Info disclosure | archives shipped to dist/ | accept | archives/ sits outside src/ and public/, Astro never reads it; dist tests already assert no unexpected files are linked |
