## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| candidate / party / search-result pages → agent | Untrusted web content read and classified by an agent |
| archive tool → public repo / private repo | Extracts public, binaries private |
| agent → web.archive.org | Rate-limited third party |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-22 | Tampering (prompt injection) | fetched pages and search results | mitigate | 03-REDACTION.md §0: instructions in fetched content are never followed; only classification and verbatim quotes; suspicious URLs listed in SUMMARY |
| T-03-23 | Spoofing | stale, parked, satirical or third-party sites taken as the candidate's | mitigate | live fetch of every URL; final URL recorded; `auteur` set from the real publisher; aggregator/press hosts excluded (HOTES_INTERDITS checked in acceptance) |
| T-03-24 | Tampering (editorial bias) | coverage levels chosen to favour a theme | mitigate | per-cell note with evidence, ranking recomputed by `classer`, research deltas listed for review, human checkpoint in 03-05 when the result differs |
| T-03-25 | Elevation of privilege | bot-protection evasion | mitigate | 403 / client-rendered → `acces: bloque` or `partiel` + `urls_bloquees`, manual capture by Erwan only (03-05) |
| T-03-26 | Information disclosure | personal data in extracts, binaries leaking | mitigate | protocol §8 step 4 grep before each commit; binaries only in the private repo, synced each batch |
| T-03-27 | Denial of service | Save Page Now limits | accept | single spaced pass, 45-minute budget, failures are warnings, resumable later |
| T-03-SC | Tampering | npm installs | accept | none |
</threat_model>
