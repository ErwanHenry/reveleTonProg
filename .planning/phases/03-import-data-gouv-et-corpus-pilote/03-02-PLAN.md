**As a** relecteur du corpus (Erwan), **I want to** importer les 59 personnalités du jeu data.gouv « statuts sourcés » en fiches candidats valides, archiver les sources primaires de leurs programmes et disposer d'un corpus pilote réel de 3 thèmes en `brouillon`, **so that** je relise des mesures sourcées et datées, sans rien d'inventé, avant toute publication.

<objective>
Vertical slice « archiver une source » : one command captures a URL (or a file Erwan saved), commits a normalized text extract with its sha256, stores the binary in a private GitHub repo, submits the URL to the Internet Archive, and writes the source YAML that the Phase 2 validator then accepts for measures citing it.

Purpose: CONT-03 and the evidence chain of every pilot measure (sourçage §5: source primaire + date de consultation + copie archivée). Decision on Playwright (Claude's discretion): **not added**. RESEARCH measured that fetch + `pdftotext` read every crawled site (no content found only after rendering); client-rendered shells are detected and routed to a manual `--file` capture by Erwan (plan 03-05 checkpoint). This keeps the zero-new-dependency rule and avoids a 170 MB browser download; Phase 5 adds Playwright for E2E with its own justification.
Output: `scripts/archive-source.ts`, five pure/IO modules under `scripts/lib/`, tests with mocked network, the private repo created and pushed, RUNBOOK section.
</objective>
