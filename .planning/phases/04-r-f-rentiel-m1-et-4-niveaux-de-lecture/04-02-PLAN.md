## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| built HTML → visitor browser | Third-party resources, inline scripts or drafts would reach every visitor |
| CLI args/env → checker | `--dist`, `--root`, `RTP_MODE` come from the caller |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | Information disclosure | third-party resources | mitigate | RESSOURCE_TIERCE on every loading attribute and CSS url()/@import; only `<a href>` may leave, with `noopener` (ASVS V14 privacy, spec §5 no external script) |
| T-04-05 | Tampering (XSS surface / CSP) | inline script/style, data: scripts | mitigate | SCRIPT_EN_LIGNE, SCRIPT_DATA_URI, STYLE_EN_LIGNE keep pages compatible with `script-src 'self'; style-src 'self'` |
| T-04-06 | Repudiation / Tampering | draft leak in production | mitigate | BROUILLON_EN_PRODUCTION fail-closed: the `data-statut-relecture="publie"` attribute is mandatory on every `.mesure`; THEME_INATTENDU for unpublished theme pages |
| T-04-07 | Information disclosure | preview indexing | mitigate | PREVIEW_INDEXABLE requires noindex on every page and `robots.txt` Disallow |
| T-04-08 | Denial of service (silent pass) | invalid mode | mitigate | resolveMode fail-closed, exit 2 on unknown mode |
| T-04-09 | Tampering (test weakening) | skeleton migration | mitigate | case count kept (≥ 4), checkDist replaces the hand-written no-JS loop with stricter rules |
| T-04-SC | Tampering | npm installs | accept | no package added |
