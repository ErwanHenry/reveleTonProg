## Phase Goal

**As a** visiteur (tout public, de l'enfant au retraité), **I want to** choisir un thème ou un candidat et lire chaque position au niveau qui me convient (en bref, en détail, pour les enfants, gros caractères), même sans JavaScript, **so that** je comprenne ce que chaque candidat propose, d'où vient chaque mesure et à quelle date, sans que l'ordre ou la présentation ne prenne parti.

<objective>
Slice « je choisis mon niveau de lecture, sans JS, et il est retenu si j'ai JS »: the 4-level toggle (radios + `:has()`), the persistence script, and the Gros caractères level (larger type that replaces the scale, 48px targets, « Ce qui me concerne »). Everything goes inside `LecteurNiveaux.astro`, which every page already uses (plan 04-03), so no page file changes.

Purpose: M1-05, M1-06, M1-09; CONTEXT (libellés des niveaux, localStorage `rtp:niveau` only, scripts classiques < 2 Ko, Aîné ≥ 20 px / cibles ≥ 44 px, bloc « ce qui me concerne » sans réordonner par CSS); RESEARCH toggle markup/CSS, `niveau.js`, Pitfalls 6, 7, 11; UI-SPEC C2, C12 and the FLAG « Aîné scale replaces, not adds ».
Output: script + vm tests, toggle component, concerne block, level stylesheet, CSS contract additions, built-page assertions.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage → script | Stored values can be tampered with by any script or extension on the origin |
| script → CSP | A non-self or inline script would break `script-src 'self'` |

| T-04-22 | Information disclosure (tracking) | localStorage | mitigate | only the key `rtp:niveau` (CNIL personalisation exemption, CONTEXT); test asserts no other key; no cookie |
