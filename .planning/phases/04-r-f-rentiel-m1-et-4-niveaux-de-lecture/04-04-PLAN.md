## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config/site.yml → every page | A wrong contact or repository is published on every measure |
| measure id → mailto/issue URL | Content-derived text enters a URL |
| preview build → web | A preview artefact could be indexed or mistaken for reviewed content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-15 | Tampering (injection into URLs) | lienMailto/lienIssue | mitigate | every component through `encodeURIComponent`; ids are schema slugs; unit tests on exact output (ASVS V5) |
| T-04-16 | Information disclosure (personal data) | contact | mitigate | only the public placeholder from config/site.yml; strict reader; acceptance grep forbids hard-coded addresses; CONTEXT: no personal address |
| T-04-17 | Spoofing | prefilled GitHub issue | accept | the link only pre-fills title/body with the measure id; the visitor writes and submits on GitHub; no `labels`/`template` reliance |
| T-04-18 | Information disclosure | preview indexing | mitigate | noindex on every page + robots.txt Disallow in preview, verified by checkDist PREVIEW_INDEXABLE in modes.cas |
| T-04-19 | Repudiation | draft mistaken for published | mitigate | text badges (never colour only) in preview; production asserts zero badge/banner strings |
| T-04-20 | Information disclosure (archives) | archive binaries | mitigate | archives never copied into dist (acceptance), extract link points to the repository blob |
| T-04-SC | Tampering | npm installs | accept | no package added |
</threat_model>
