**Design (D-04, D-07; research §2; orchestrator decisions « majeur 4 » and « mineur 7 »):**
- `optionsSsh(cfg, agent)` returns `['-F', '/dev/null', '-i', cfg.cle, '-o', 'IdentitiesOnly=yes', '-o', 'IdentityAgent=<agent.socket>', '-o', 'BatchMode=yes', '-o', 'StrictHostKeyChecking=yes', '-o', 'UserKnownHostsFile=<cfg.knownHosts>', '-o', 'ConnectTimeout=15']`; ssh env = `envDeBase()` (no SSH_AUTH_SOCK).
- `appelerVerbe(cfg, agent, exe, verbe, args, lancer)`: verbe etat | activer | retour; target enum and sha regex checked before spawn; last ssh arguments `<user>@<host>` and `"<verbe> <cible>[ <sha>]"`; delay 60 s; returns stdout trimmed or throws a Sortie carrying the exit code and `masquer(stderr)` (64, 65, 66, 75 named as in the header of ops/commande-deploiement.sh).
- Parsers with the workflow regexes: `lireEtat` (`etat cible=<c> courant=<sha|aucun> versions=<n> libre_mio=<n>`, aucun gives null), `lireActive`, `lireRetour`; anything else null.
- `varianteRsync(exe.rsync, lancer)`: `openrsync` when `--version` contains openrsync, `rsync3` when its first line starts with `rsync  version 3`, else `inconnue`. `exigerRsync3(variante)`: not rsync3: Sortie code 2 « rsync 3 requis pour l'envoi (openrsync refuse les options de la CI et n'est pas vérifié avec le serveur) : brew install rsync, puis RTP_RSYNC=<chemin> dans ~/.config/rtp/deploiement.env ».
- `envoyer(cfg, agent, exe, dist, cible, sha, lancer)`: calls `exigerRsync3` first; `<exe.rsync> -rt --stats -e "<exe.ssh> <optionsSsh joined by spaces>" <dist>/ <user>@<host>:<cible>/<sha>/`; no `-l`, no `--chmod` (modes normalized by plan 02); delay 15 min; output masked.
- `versionServie(cfg, exe, lancer)`: needs cfg.url; password file read, trailing newline removed, backslash and double quote escaped like ci.yml `config_curl`; `entree` = `user = "<u>:<p>"\n`; `<curl> -fsS --retry 5 --retry-all-errors --retry-delay 3 --max-time 20 --config - -o <tmp>/version.json <url>/version.json`, then `<jq> -r .commit`; second call `-o /dev/null -D <tmp>/entetes <url>/`; returns `{ commit, hsts, csp }`; temp dir 0700 removed in finally; errors masked.
- CLI `scripts/deploy-local.ts`: `executer(argv, deps): Promise<number>`, parseArgs strict, `import.meta.main` guard, Sortie of plan 02. `Dependances = { lancer?: Lanceur; maintenant?: () => Date; home?: string; racine?: string; ecrire?: (l: string) => void }` and nothing else: no `terminal`, `lireLigne` or `confirmer` field, ever (plan 05 reads the confirmation on /dev/tty inside the module). This plan implements one subcommand, `etat`: lireConfig, resoudreExecutables (ssh, ssh-agent, ssh-add, ssh-keygen, curl, jq, git), ouvrirAgent (passphrase required), etat, versionServie if url; prints target, current commit and its subject when local git knows it, versions, free space, served commit, HSTS and CSP. Other subcommands: exit 2 with the usage text listing only what exists.
