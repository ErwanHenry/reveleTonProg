# Phase 9.2 Plan 01 : CI locale (`npm run ci:local`) Summary

`npm run ci:local` rejoue sur le Mac les 19 étapes locales des jobs verifier, secrets et e2e de ci.yml (9 étapes GitHub exclues avec leur raison), une ligne par étape, et écrit un reçu `~/.cache/rtp/ci/<sha>.json` (0700/0600) seulement pour un arbre propre et un HEAD immobile ; un test de parité épingle le catalogue à ci.yml.

## Ce qui a été fait

- **Tâche 1** : `scripts/lib/processus.ts` (`lancer` sans shell, environnement exact, délai avec SIGTERM puis SIGKILL, ligne de progression chaque minute ; `envDeBase` en liste blanche) et le catalogue `ETAPES` / `EXCLUSIONS_CI` de `scripts/lib/ci-local.ts`, avec `ecartsParite` (noms, rangs des exclusions, ordre, run des étapes « identique », toutes les variables `RTP_`, arguments de gitleaks). Test de parité avec 9 cas de mutation.
- **Tâche 2** : exécution (`executerEtapes`, un échec n'arrête pas la suite), base de ids.lock (`baseIdsLock` : fetch, merge-base ou premier parent, échec fermé), reçu (`ecrireRecu`, `lireRecu`, `recuValidePourDeploiement` avec un motif propre à chaque refus), verrou (`prendreVerrou` par `mkdir` et pid, repris s'il est abandonné), CLI `scripts/ci-local.ts` et script npm.

## Deviations from Plan

1. **[Rule 1 - test] Variable `__CF_USER_TEXT_ENCODING`** : sur macOS, CoreFoundation la pose dans le processus enfant lui-même ; le test « passe exactement l'environnement donné » l'écarte nommément (aucune autre variable admise). Commit e6031ea.
2. **Champs ajoutés aux interfaces du plan** (noms existants gardés) : `ExclusionCi.rang` (repère du rang dans ci.yml, pour signaler une exclusion déplacée), `EtapeLocale.heriter` (sortie en direct de npm test, des builds et de e2e), `Dependances.versionNode` (contrôle de Node 24 injectable, prévu par le plan), un second paramètre facultatif `avertir` de `prendreVerrou` (l'avertissement de reprise passe par la sortie de la commande).
3. **5 substitutions au lieu de 4** : « Analyser l'historique git » n'a pas exactement le run de ci.yml (binaire dans `RUNNER_TEMP`) ; elle est donc une substitution, mais ses arguments restent comparés à ceux de ci.yml.
4. **`executer` attrape lui-même `Sortie`** et renvoie son code (le message passe par `ecrire`) ; le garde `import.meta.main` le fait aussi par sécurité.
5. **Pas de push** (consigne de la session principale) : `gh run list` après push reste à faire par elle.
