**Design (Claude's discretion, D-04, D-05; orchestrator decision « bloquant 2 »):**
- Fingerprint: walk with `node:fs` (`lstatSync`, never follow a link), paths `./rel/path`, sorted by `Buffer.compare` of their UTF-8 bytes (`LC_ALL=C sort -z`), text `<hex>  ./rel/path\n` per file, sha256 of that text; empty tree gives sha256 of the empty string.
- `trouverSpecial(d)`: first entry neither a regular file nor a directory, or a regular file with `nlink > 1` (server code 65), relative path, else null.
- `resoudreExecutables(noms, chemin PATH)`: for each name, the first executable regular file found in the PATH dirs (`node:fs`, no shell, no `which`), then `fs.realpathSync`; returns `{ nom, chemin, empreinte }` with the sha256 of the file; a missing name: Sortie code 2 naming it. A name given as an absolute path (RTP_RSYNC) is taken as is.
- `prendreInstantane({ racine, fichiers, executables })`: sha256 of `<racine>/.git/config`, of the `.git/hooks` tree (fingerprint function above, links refused), of each listed file (missing file recorded as absent), and the executables map. `comparerInstantanes(avant, apres)` returns the list of differences (path or executable name, never content); non-empty: Sortie code 1 « intégrité locale modifiée pendant la build : <liste> ; déploiement arrêté ».
- Sandbox profile (`profilSandbox({ home, worktree, gitWorktreeDir, tmpdir, cacheNpm, lecturesInterdites })`), every path through `fs.realpathSync` when it exists (the sandbox matches real paths; /var is /private/var), paths with `"` or `\` refused:
  `(version 1)(allow default)(deny file-write*)(allow file-write* (subpath "<worktree>") (subpath "<gitWorktreeDir>") (subpath "<tmpdir>") (subpath "<cacheNpm>") (literal "/dev/null") (literal "/dev/tty"))(deny file-read* <one (literal …) per configured secret or config file> (subpath "<home>/.config/rtp") (subpath "<home>/.ssh") (subpath "<home>/.config/gh"))`.
  `cacheNpm` = `npm config get cache` resolved before the build outside the sandbox (default `~/.npm`). If a real build needs another writable path (found by running Task 2 against this repository), add the narrowest path, say why in a comment and in the SUMMARY; never a parent of `~/.config`, `~/.ssh`, the main `.git` or HOME itself.
- Refusal before the build: any path of `lecturesInterdites`, `~/.config/rtp`, `~/.ssh` or `~/.config/gh` that is under the worktree (realpath prefix check): Sortie code 2.
- `sandbox-exec` resolved to an absolute path; absent: Sortie code 2 « sandbox-exec introuvable : la build de déploiement ne peut pas être cloisonnée, déploiement refusé ».
- Build env: `envDeBase()` (plan 01) plus `RTP_CONTENT_ROOT=.`, `RTP_DEPLOIEMENT` ('1' production, '0' essai), `GITHUB_SHA=<sha>`, `npm_config_update_notifier=false`, `npm_config_fund=false`, `npm_config_cache=<cacheNpm>`. The parent env is never passed as is.
- Worktree: `git worktree add --detach <tmpdir>/rtp-deploiement-<sha 12>-<random> <sha>` (outside the sandbox), `gitWorktreeDir` = `<racine>/.git/worktrees/<basename>` read from `git rev-parse --git-dir` inside the worktree; removal by `git worktree remove --force` then `git worktree prune`, in `finally` and in `nettoyer()`. Delays: npm ci 20 min, audit 5 min, build 25 min, check-dist 10 min.
- `construireDeploiement` order: resolve sandbox-exec, npm and the sending executables; refusal checks; `prendreInstantane` (avant); worktree; the four npm commands as `<sandbox-exec> -p <profil> <npm> <args>`; `prendreInstantane` (apres) and `comparerInstantanes`; `normaliserModes`, `trouverSpecial`, `jq -e --arg s <sha> '.commit == $s' dist/version.json`, `empreinteArbre`. Returns the snapshot taken before the build so plan 06 can compare again after the confirmation.
- Guards as before: `lireCheminsHorsSite(texte)` (single line `^  CHEMINS_HORS_SITE: "(.*)"$`, else throws; test compares with `parse(ci.yml).env.CHEMINS_HORS_SITE`), `siteTouche` (base null, unknown or not an ancestor: true by prudence; else `git diff --no-renames --name-only -z` to `bash ops/site-touche.sh`; verdict other than true/false throws), `teteAdmise` (ci.yml lines 469 to 497 rule), `decisionGel` (wraps `evaluerGel` and `nettoyerJustification` of scripts/garde-gel.ts), `verifierRecu` (wraps plan 01), `teteOrigine` returns `{ tete, fetchOk }` (plan 06 refuses when fetchOk is false, before and after the confirmation).
