**Design:**
- Local paths from `os.homedir()` (tests set HOME): `~/.config/rtp/deploiement.env`, receipts `~/.cache/rtp/ci/`, journal `~/.local/state/rtp/deploiements.jsonl`, lock `~/.cache/rtp/deploiement/.verrou`.
- Keys: `RTP_CIBLE` (essai|production, required), `RTP_HOTE` (required, `^[A-Za-z0-9.:-]+$`, a real host name or address; ~/.ssh/config is ignored by `-F /dev/null`), `RTP_UTILISATEUR` (required, `^[a-z_][a-z0-9_-]*$`), `RTP_URL` (optional, `https://` only, no user info, no space), `RTP_CLE` (default `~/.config/rtp/rtp-deploy-mac`), `RTP_KNOWN_HOSTS` (default `~/.config/rtp/known_hosts-deploy`), `RTP_FUMEE_UTILISATEUR` (default `sonde`), `RTP_FUMEE_MOT_DE_PASSE` (path, default `~/.config/rtp/sonde-pass`), `RTP_RSYNC` (default `rsync`; an absolute path to a Homebrew rsync 3 is the expected value, plan 04 refuses openrsync for a real send). `~/` expanded; blank lines and `#` comments allowed; surrounding double quotes stripped; no expansion, no `export`. Deployment file, key and password file: `mode & 0o077` = 0; `<key>.pub` must exist; known_hosts non-empty; no whitespace in paths. Export `CLES_CONFIG` (the list of keys, used by the docs test of plan 07).
- `cheminsSecrets(cfg, home)`: deployment file, key, key.pub, known_hosts, password file: the list plan 06 passes to the build as `lecturesInterdites` and `fichiersSurveilles`.
- `masquer(texte, cfg)`: replaces every occurrence of `cfg.url` (and of the URL without trailing slash) by `<url>`, of the URL's host and of `cfg.hote` by `<hôte>`, of `<user>@` by `<utilisateur>@` and of the user as a whole token (`\b` boundaries, regex-escaped) by `<utilisateur>`; longest values first; empty values ignored.
- `cleChiffree(cle, exe, lancer)`: runs `<ssh-keygen> -y -P '' -f <cle>` with stdout and stderr captured and discarded (never returned, never printed); exit 0 means no passphrase. Comment: the command prints the public key only, which is not secret, and the output is dropped anyway.
- `ouvrirAgent(cfg, { exe, lancer, ecrire })`: (1) cleChiffree false: Sortie code 3 « la clé <chemin> n'a pas de phrase de passe : refusée ; la poser avec ssh-keygen -p -f <chemin> » ; (2) 0700 temp dir by `fs.mkdtempSync`, `<ssh-agent> -a <dir>/agent.sock -s`, parse `SSH_AGENT_PID` ; (3) `<ssh-add> -t 900 <cle>` with `heriter: true` (prompt on the terminal), env = `envDeBase()` + `SSH_AUTH_SOCK=<socket>` + `SSH_ASKPASS_REQUIRE=never`, no DISPLAY, no SSH_ASKPASS; failure (wrong passphrase, no terminal): Sortie code 3 « clé non chargée : la phrase de passe doit être tapée par Erwan dans un terminal » ; (4) returns `{ socket, fermer }`; `fermer()` runs `<ssh-agent> -k` with SSH_AGENT_PID and SSH_AUTH_SOCK in its env and removes the dir; idempotent; registered on SIGINT, SIGTERM, SIGHUP and removed by `fermer`. `exe` is the absolute-path map from plan 02 (`resoudreExecutables`).
