- `build: { inlineStylesheets: 'always' }`, keep `vite: { build: { assetsInlineLimit: 0 } }` (otherwise assets become data: URIs).
- `security: { csp: { directives: ["default-src 'none'", "img-src 'self'", "base-uri 'none'", "form-action 'none'", "object-src 'none'"], scriptDirective: { hashes: [<sha256-niveau>, <sha256-ordre>] } } }`. Hash strings are `sha256-<base64>` WITHOUT quotes in the config; Astro quotes them in the meta.
- Astro emits ONE meta per page at the END of <head> (after the ordre script, before the <style>), content like `default-src 'none';img-src 'self';base-uri 'none';form-action 'none';object-src 'none'; script-src 'self' 'sha256-…' 'sha256-…' <5 Astro island-directive hashes>; style-src 'self' 'sha256-…'…;`. Astro does NOT hash is:inline scripts (hence scriptDirective.hashes). The 5 extra script hashes cannot be removed: check-dist must require inclusion, never equality.
- `is:inline` disappears from the HTML; `compressHTML: true` keeps script and style text byte-identical.

From scripts/lib/check-dist.ts (current): `LIMITES = { brut: 500_000, gzip: 100_000, script: 2048 }`; `CODES_CHECK_DIST` (as const array, test asserts no duplicate and every emitted code is listed); `OptionsCheckDist { mode; cellulesParTheme?; deploiement? }`; `signaler(code, fichier, message, severite = 'erreur')`; rules at lines ~194-273 (dist .js/.css loop for SCRIPT_TROP_LOURD and RESSOURCE_TIERCE, per-node loop for SCRIPT_DATA_URI, RESSOURCE_TIERCE, SCRIPT_EN_LIGNE, SCRIPT_NON_BLOQUANT, META_REFRESH, BASE_INTERDITE, STYLE_EN_LIGNE).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository source → built page | Inline code must be exactly the reviewed source files |
| built page → visitor browser | The CSP meta decides which inline code runs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01 | Tampering (script injection) | inline <script> in dist | mitigate | check-dist SCRIPT_EN_LIGNE (byte identity with src/scripts) + SCRIPT_SANS_EMPREINTE (hash in effective directive), CSP without 'unsafe-inline' (CSP_TROP_PERMISSIVE) |
| T-07-02 | Tampering (style injection) | inline <style>, style= | mitigate | STYLE_SANS_EMPREINTE, STYLE_EN_LIGNE on style=, RESSOURCE_TIERCE on inline CSS text |
| T-07-03 | Denial of service (stale hash blocks the site) | astro.config.mjs hashes | mitigate | one helper hashes the source files at build time; LF-only guard (.gitattributes + test) so Node and browser hash the same bytes |
| T-07-04 | Elevation of privilege (order script runs before the meta) | ordre.js in <head> | transfer | the meta cannot cover it (Pitfall 1); the header CSP rendered by 07-07 into deploy/caddy/site.caddy covers it from the first byte (applied in Phase 8); check-dist still proves identity and hash |
| T-07-05 | Information disclosure (rule loss) | check-dist rewrite | mitigate | old codes removed only in the same commit as their replacement; inline SCRIPT_TROP_LOURD, SCRIPT_NON_BLOQUANT, RESSOURCE_TIERCE extended |
</threat_model>
