# Phase 4 — UI Design Contract

> Visual and interaction contract for Phase 4 (Référentiel M1 et 4 niveaux de lecture). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Stack: Astro 7 static, zero required JS, plain CSS files (`src/styles/base.css`, `src/styles/niveaux.css`), no CSS framework, no React, no component library.
> Tags used below: **[LOCKED]** = decision of Erwan or an inherited constraint (CONTEXT.md / RESEARCH.md / CAHIER-DES-CHARGES §3, §5, §10); **[DEFAULT]** = chosen here under "Claude's Discretion", changeable at the first checkpoint without touching any locked rule.
> Contrast ratios in this document were computed numerically (WCAG 2.x relative luminance, script run 2026-11-03), not estimated.

## Spacing Scale

Declared values (all multiples of 4), expressed in `rem` in CSS (1rem = 16px) so that spacing follows user text size:

| Token | Value | rem | Usage |
|-------|-------|-----|-------|
| xs | 4px | 0.25rem | Gap between a term and its `?` marker, icon gaps, inline padding of badges |
| sm | 8px | 0.5rem | Gap between stacked text lines inside a card, gap between the two report links, vertical padding of labels |
| md | 16px | 1rem | Default element spacing, card padding (mobile), page side margin (mobile), gap between blocks inside a measure |
| lg | 24px | 1.5rem | Card padding (≥ 600 px), grid gap between cards, section padding, page side margin (≥ 600 px) |
| xl | 32px | 2rem | Gap between page sections, page side margin (≥ 960 px) |
| 2xl | 48px | 3rem | Gap between major sections (header band to content, list to footer) |
| 3xl | 64px | 4rem | Top of hall page, bottom page margin |

Exceptions (all justified, none is a spacing value):
- Touch target height: **44px (2.75rem)** minimum for every standalone control and link in every mode (radio labels, card link, "N autres mesures", report links, `summary`, skip link); **48px (3rem)** in Gros caractères mode [LOCKED ≥ 44 px, M1-09; 48 is the DEFAULT for Aîné].
- Stroke widths (borders and outlines, not spacing): 1px (card border), 2px (control border, dotted term underline, term marker ring, focus halo), 3px (focus ring, link hover underline), 4px (theme bar on cards, quotation bar), 8px (theme bar on `/themes/` tiles and theme page header).
- Border radius: 4px on controls, cards, popover (sober, no pill shapes).
- Inline terms in running text are exempt from the 44 px rule (WCAG 2.5.8 inline exception) but get `padding-block: 4px` so the hit area is at least 24 px.

## Typography

Font stack: system sans-serif [LOCKED]. Exactly 4 sizes and 2 weights (400 regular, 600 semibold). All sizes in `rem`, all media queries in `em`, so text-size zoom and the 160 % mode reflow the layout.

| Role | Normal size | Gros caractères size | Weight | Line height | Used for |
|------|-------------|----------------------|--------|-------------|----------|
| Label | 16px (1rem) | 20px (1.25rem) | 400 (600 for h4 and labels of controls) | 1.5 | Source block, dates, "N autres mesures", coverage line, badges, report links, toggle labels, footer, breadcrumb, popover source line |
| Body | 18px (1.125rem) | 22px (1.375rem) | 400 (600 for h3 card name and mesure `<strong>` lead-ins) | 1.5 | Rédactions (all 4 levels), empty-state text, intro paragraphs, popover definition, `<dd>` of "Mots expliqués" |
| Heading | 24px (1.5rem) | 28px (1.75rem) | 600 | 1.2 | h2 (section titles, theme names on candidate page, "Ce qui me concerne") |
| Display | 32px (2rem) | 36px (2.25rem) | 600 | 1.2 | h1 only (one per page) |

Rules:
- **Aîné body ≥ 20 px [LOCKED, M1-09]**: body is 22 px, the smallest text (Label) is 20 px. The scale switches on `.lecteur:has(> .niveaux #niv-aine:checked)` and applies to the toggle and to the whole `.lecteur-contenu`. Site header/footer outside `.lecteur` keep the Normal sizes but keep 44 px targets. [DEFAULT]
- Heading hierarchy: h1 Display 32/600; h2 Heading 24/600; h3 (candidate name on a card, theme tile name) Body 18/600; h4 (mesure title) Label 16/600. No other size exists. Do not add a fifth size.
- Maximum line length for prose: `max-width: 68ch` on rédactions, intro paragraphs and popover content. Cards are narrower than this and wrap naturally.
- `overflow-wrap: break-word; hyphens: auto` on names, titles and URLs (lang="fr"); never `text-overflow: ellipsis`, never `-webkit-line-clamp`: **no truncation anywhere** (a résumé is ≤ 25 words, a détaillé is ≤ 200 words, they must be shown in full).
- **160 % mode [LOCKED, §10]**: no site control; the contract is "layout survives browser text zoom to 160 % and page zoom to 400 % at 320 CSS px without horizontal scroll, without clipped or overlapping text". Consequences: no fixed `height`/`max-height` in px on text containers (only `min-height` for targets), no `overflow: hidden` on text containers, grid tracks use `minmax(min(100%, 18rem), 1fr)`. Combination Gros caractères + 160 % (≈ 35 px body) must still read as one column with no horizontal scroll. Verified by Phase 5 Playwright; Phase 4 ships the CSS that makes it true.
- Numbers (dates, percentages) use the default proportional digits; no `font-variant-numeric` games.

Implementation contract:
- Ten rules in `base.css`: `[data-theme="logement"] { --theme: #A3401C; }` and so on. Theme `id` values come from the corpus (`themes/*.yaml`); the slugs above are the proposed ids and must be reconciled with Phase 3's theme files. A theme id with no rule falls back to `--theme: var(--encre-douce)` (neutral, still AA); a unit test lists corpus theme ids and fails on a missing rule in `production` mode. No colour is added to the YAML schema.
- Minimum perceptual distance between any two theme colours is ΔE76 = 18.1 (closest pair: `impots` / `securite`). Colour is therefore never the only carrier of identity: the theme name is always written next to its colour bar. [DEFAULT]
- **Neutrality guard [LOCKED, §10]**: no colour is ever bound to a candidate or a party. On a theme page, every card uses the same theme colour. On a candidate page, colour varies only by theme section. A party name is always plain `--encre-douce` text. The pictogram is identical and neutral for every candidate. No red/orange/blue is used to signal "good/bad", "left/right" or status.
- No photo, no logo of any party or candidate. [LOCKED]

Accent (`--theme`) reserved for, and only for:
1. 8px top bar of the theme page header band (`/themes/<id>/`).
2. 4px top border of each `.cellule` card on a theme page.
3. 8px left bar of each theme tile on `/themes/` and in the "Ce qui me concerne" block.
4. Text colour and 4px left bar of the h2 theme title in each section of a candidate page.
5. Text colour of the h1 on a theme page.

Accent is **never** used for links, buttons, toggle states, focus rings, popover terms, badges, empty states, source blocks or statut text. Links are `--encre` with underline; selected toggle is `--encre` fill. This keeps the accent at about 10 % of the pixels.

## Layout and Breakpoints (mobile-first)

Container: `max-width: 72rem` (1152px), centred, side padding per breakpoint. Single column of document flow; the card grid is intrinsic:

```
.cellules { display: grid; gap: 24px; grid-template-columns: repeat(auto-fill, minmax(min(100%, 18rem), 1fr)); }
.lecteur:has(> .niveaux #niv-aine:checked) .cellules { grid-template-columns: repeat(auto-fill, minmax(min(100%, 22rem), 1fr)); }
```

| Breakpoint (em, so zoom triggers it) | px at 16 px root | Changes |
|--------------------------------------|------------------|---------|
| base | 0–599 | 1 column; side padding 16px; header stacked (site name above nav); level toggle in a 2 × 2 grid; order toggle stacked |
| `min-width: 37.5em` | 600 | side padding 24px; level toggle in one wrapping row; card padding 24px; grid yields 2 columns |
| `min-width: 60em` | 960 | side padding 32px; header on one row; grid yields 3 columns (normal) or 2 (Gros caractères); max container reached |

Cards are of **fixed structure, not fixed pixel size** (M1-08): every `.cellule` has the same zones in the same order, equal width (grid), and equal height within a row (grid stretch + `display: flex; flex-direction: column` with the footer pinned by `margin-top: auto`). No `height` in px, no clamp. Heights change with the active level (résumé shorter than enfant) but a row is always aligned.

Page skeleton (every page):
1. Skip link "Aller au contenu" (first focusable, visible on focus).
2. `<header>`: site name (link to `/`), `<nav aria-label="Navigation principale">` with "Thèmes" and "Candidats".
3. Preview banner (preview build only).
4. `<main id="contenu">`: breadcrumb, h1, intro, `.lecteur` wrapper (toggle first, then content).
5. `<footer>`: "Dernière mise à jour" line and cookie line.

Non-sticky everywhere (toggle and header are not sticky) [DEFAULT, resolves RESEARCH A7: avoids WCAG 2.4.11 focus obscuring; `scroll-padding-top: 16px` is still set]. Long pages offer "Changer le niveau de lecture" at the end of the list (see copy deck) as a no-JS anchor to `#niveaux`.

## Components

### C1. Header, nav, breadcrumb
- Site name: Body 18/600, `--encre`, underline on hover only. Nav links: Label 16, 44px min height, underlined, `padding-inline: 8px`; current page `aria-current="page"` + weight 600 (no colour change).
- Breadcrumb: Label 16, `--encre-douce`, items separated by a CSS `/` (ASCII) with `aria-hidden`; last item not a link.

### C2. LecteurNiveaux — the 4-level toggle [LOCKED mechanism, M1-05; visuals DEFAULT]
Markup per RESEARCH (fieldset + legend + 4 radios `name="niveau"` `autocomplete="off"` + labels, `role="status"` region, then the classic script, then content). Visual contract of each option (`.niveau` = radio overlaid transparently on its label; the radio is never `display: none`):

| State | Label background | Text | Border | Extra cue (not colour-only) |
|-------|------------------|------|--------|------------------------------|
| Unselected | `--carte` | `--encre` 16/600 | 2px `--bord-fort` | hollow 12px CSS circle before the text |
| Hover (unselected) | `--panneau` | `--encre` | 2px `--bord-fort` | same hollow circle; `cursor: pointer` |
| Selected (`:checked`) | `--encre` | `#FFFFFF` (15.80:1) | 2px `--encre` | filled 12px white dot before the text |
| Focus-visible (any) | unchanged | unchanged | unchanged | focus ring (see Interaction) drawn on the label via `input:focus-visible + label` |
| Selected + focus | selected look | selected look | selected look | focus ring with 2px white halo so it stays visible on the dark fill |
| Forced colours (`forced-colors: active`) | `Canvas` | `CanvasText` | selected: `Highlight` border 4px + `HighlightText` on `Highlight` fill | shape cue unchanged |
| Disabled | not applicable | | | no disabled state exists |

Geometry: label `min-height: 44px` (48px at Aîné), `padding: 8px 16px`, `border-radius: 4px`, options separated by 8px; legend Label 16/600 above; help line "Ce choix s'applique…" Label 16 `--encre-douce` below. Base: 2 × 2 grid; ≥ 37.5em: single wrapping row. Option order is fixed: En bref, En détail, Pour les enfants, Gros caractères. Default checked without JS and without stored value: **En bref** [LOCKED by research].

Content switching (CSS only, `:has()` on `.lecteur`): exactly one `.redaction` visible per measure. `.redaction > .etiquette` (the level name) is visually hidden when `:has()` is supported (still read) and visible with a 1px top rule when not supported (all four levels then show, page stays complete). Source block and report links are outside the level blocks and always visible.

### C3. OrdreCandidats — order control (JS only)
Fieldset "Ordre des candidats" with 2 radios (same visual states as C2): "Ordre alphabétique" (default), "Ordre aléatoire". Container carries `hidden` in the HTML; `ordre.js` reveals it. Help text always visible: alphabetical rule + neutrality; a second sentence "L'ordre aléatoire demande JavaScript." is visible **only** when JS is off (hidden when `ordre.js` has run; mechanism = an attribute set on `<html>` by `ordre.js`, within its 2048-byte budget). While the shuffle is pending, lists are `visibility: hidden` (no layout shift) with the 1.5 s CSS safety reveal [LOCKED by RESEARCH Pitfall 8]. No animation on reorder.

### C4. Cellule — candidate card on a theme page (`li.cellule[data-rang]`) [LOCKED structure, M1-08]
Zones, top to bottom, identical for every candidate:
1. Header row: neutral pictogram (CSS-drawn bust, 48 × 48, background `#D5D2CB`, shapes `--bord-fort` 3.30:1, `aria-hidden`, identical for all) + column with candidate name (h3, Body 18/600, link to `/candidats/<id>/#<theme>`, min target 44px) and party line (Label 16, `--encre-douce`, "Parti revendiqué : …" or "Sans étiquette de parti déclarée").
2. Body: **exactly one** measure (first by title order) via C5, or an empty state (C6).
3. Footer (pinned to bottom): link "N autres mesures" (Label 16, underlined, 44px target) to `/candidats/<id>/#<theme>`; absent when N = 0 (the footer zone keeps its space only through `margin-top: auto`, no placeholder text).
Card chrome: `--carte` fill, 1px `--bord-carte` border, 4px top border in `--theme`, 4px radius, padding 16px (24px ≥ 600 px).
Page-level, above the grid: coverage line (C7). Below the grid: `renonce` section (C8) and the pressentis/empêchés count line.

### C5. Mesure (`article.mesure[data-statut-relecture]`)
- h4 title: Label 16/600.
- Rédaction of the active level, Body size, `max-width: 68ch`.
  - En bref: one sentence, plain.
  - En détail: paragraphs; the exact quotation from the programme is a `<blockquote data-citation>` with 4px `--bord-fort` left bar, 16px left padding, shown between « » and followed by its source link.
  - Pour les enfants: sentences with glossary terms (C9).
  - Gros caractères: same markup, Aîné scale.
- Source block `.source` (always visible, Label 16, `--encre-douce`, top rule 1px `--bord-carte`, 8px top padding), in this order:
  1. "Source primaire : {titre}" (title wrapped in `data-citation`)
  2. "Consultée le <time datetime="AAAA-MM-JJ">{date}</time>"
  3. Link "Lire le document original" (external `https:`, `rel="noopener noreferrer"`)
  4. Link "Copie archivée (Wayback Machine)" when a Wayback URL exists; plus "Extrait archivé, empreinte sha256 {12 caractères}" linking to the GitHub blob of the archived extract [RESEARCH Q4/A4]
  5. Report links on their own line, 8px apart: "Signaler une erreur (courriel)" and "Signaler une erreur (GitHub)" (each with a visually hidden suffix naming the measure)
- Links in this block are stand-alone and keep the 44px target (stacked, 8px gap).
- Preview only: badge (C11) right-aligned in the measure title row.

### C6. Empty states (typed, dated) [LOCKED wording, M1-01]
Rendered in the card body (theme page) or the theme section (candidate page) in place of a measure:
- Container: `--panneau` fill, 1px `--bord-carte` border, 16px padding.
- Text: Body 18/400, `--vide` (grey, 5.81:1 on `--panneau`). Never red, never an icon, never a theme colour.
- Two types, one line each, the date being a `<time>`:
  - `non_precise` → "Non précisé dans les sources consultées le {date}."
  - `programme_non_publie` → "Programme non publié à ce jour. Vérifié le {date}."
- Optional second line (Label 16, `--encre-douce`) when the data lists them: "Sources consultées : {titre}, {titre}."
- Preview only, third type `non_verifie` → "Case non vérifiée : à compléter avant publication." with the draft badge. Cannot occur in production (build throws).
- A statut still under review (RESEARCH A1) → "Statut en cours de vérification" in the same grey style.

### C7. Couverture — coverage line (top of a theme page)
One sentence in a `--panneau` band, Label 16 (Body at Aîné), `--encre`, placed after the h1 and intro and before the order control. Counts are numbers in plain text; no chart, no colour. Copy in the deck.

### C8. "Ne se présentent pas" (`details`)
Native `<details>` closed by default, after the grid. `summary` Body 18/600, min-height 44px, 1px `--bord-carte` border, `--carte` fill, native marker kept. Content: list (`data-ordonnable`, alphabetical) of name (link to the candidate page), motif text, date, source link. Items are not `.cellule` (excluded from the cell count). Pressentis and empêchés: only one count line under the section.

### C9. TexteEnfant — glossary terms and definitions [LOCKED, M1-10]
- Term = `<button type="button" class="terme" popovertarget="…">mot</button>` immediately followed by `<span id="…" popover class="definition">…</span>` (one popover per occurrence, ids suffixed with the mesure slug).
- Term style, distinct from links:
  - Link = solid 1px underline, offset 3px, `--encre`.
  - **Term = dotted underline** (`text-decoration: underline dotted; text-decoration-thickness: 2px; text-underline-offset: 4px`), `--encre`, 400 weight, button reset (`background: none; border: 0; padding: 4px 0; font: inherit; color: inherit; cursor: pointer`).
  - **Marker**: a CSS-drawn circle after the word: `.terme::after { content: "?"; content: "?" / ""; display: inline-block; box-sizing: border-box; width: 1.25em; height: 1.25em; margin-inline-start: 4px; border: 2px solid currentColor; border-radius: 50%; font-size: 0.75em; font-weight: 600; line-height: 1; text-align: center; text-decoration: none; }` (plain ASCII `?`; the plain declaration comes first, the empty-alt one second; accessible name stays the word). No `ⓘ`, no emoji, no image.
  - Open state (`aria-expanded="true"`): background `--panneau`.
- Popover (`.definition`): `--carte` fill, 2px `--encre` border, 4px radius, padding 16px, Body 18/400, `max-width: min(calc(100vw - 32px), 24rem)`, `max-height: 80vh; overflow: auto`, centred by the user agent (no anchor positioning), `::backdrop { background: rgba(31, 35, 40, 0.4); }`. One sentence only. For `type: parti` entries add a second line, Label 16 `--encre-douce`: "Définition donnée par {titre}, {date}." No close button: dismissal is light-dismiss (click/tap outside), Esc (focus returns to the term), or toggling the term again. [DEFAULT, matches verified behaviour]
- Fallback `@supports not selector(:popover-open)`: `.definition { display: none }`, `.terme { text-decoration: none; color: inherit }`, `.terme::after { content: none }`, plus a visible hint paragraph (copy deck) shown only in this branch.
- Performance acceptance: switching to Pour les enfants with 111 terms must stay under 50 ms layout in Chrome (prototype baseline 32 ms; the `ⓘ` glyph cost 155 ms and is forbidden).

### C10. MotsExpliques — "Mots expliqués" list (`details`)
Shown at the Pour les enfants level only (hidden by the same `:has()` switch at other levels), placed after the list of cards. `summary` "Mots expliqués ({n})" Body 18/600, 44px target. Body: `<dl>`; one `<dt>` (Body 18/600) and `<dd>` (Body 18/400) per **distinct** term on the page, alphabetical; party entries add the "Définition donnée par…" line. Closed by default; works with and without Popover support.

### C11. BadgeBrouillon and preview banner (preview build only; production emits no such markup) [LOCKED, M1-11]
- Badge: Label 16/600, `--encre`, `--panneau` fill, **dashed** 2px `--encre` border, `padding: 4px 8px`, 4px radius. Text only, never colour-only. Texts: "brouillon, non relu" (statut `brouillon`) and "relu, pas encore publié" (statut `relu`). `publie`: no badge.
- Banner: full-width `--panneau` band under the header, dashed 2px bottom border `--encre`, Body 18/600 centred text (copy deck), above the page, on every page. `meta robots noindex` is also emitted (not visual).

### C12. Bloc « Ce qui me concerne » (Gros caractères only) [LOCKED, M1-09]
First element of `.lecteur-contenu` in the DOM (never reordered with CSS `order`), `display: none` except at Aîné. Contents: h2 (Heading), one intro sentence, then a list of links to themes with `prioritaire_aine` (tiles: `--carte` fill, 1px `--bord-carte` border, 8px left bar in the theme colour, theme name Body 18/600 as the link, 48px min height, full-width tile is the target). On a theme page the current theme shows "(page affichée)" and `aria-current="page"`. On a candidate page the links point to the theme sections of that page (`#<theme>`). Includes the neutrality sentence "Cette sélection ne classe pas les candidats."

### C13. Hall (`/`), `/themes/`, `/candidats/`

### Focus [LOCKED: keyboard navigation complete, §10]
- Never `outline: none`. All focusable elements: `:focus-visible { outline: 3px solid #1F2328; outline-offset: 2px; box-shadow: 0 0 0 2px #FFFFFF; }` (ring 15.12:1 on `--fond`; the white halo keeps it visible on the dark selected toggle and on the dark popover border). - Skip link: positioned off-screen, visible on focus (`--encre` fill, white text, 16px padding).
- Focus order = DOM order: header, toggle, order control, "Ce qui me concerne" (Aîné), cards in current order, `renonce`, "Mots expliqués", footer. No `tabindex` greater than 0.
- Esc closes a popover and returns focus to its term (native).

### Hover, active, motion
- Hover: links thicken the underline to 3px; unselected toggle gets `--panneau`; cards do not change (they are not clickable as a whole). No transform, shadow or colour shift.
- No CSS transition or animation anywhere, except the 0 s safety reveal keyframe of the shuffle (not gated by `prefers-reduced-motion`, it is not motion). `scroll-behavior` stays `auto`. [DEFAULT; satisfies "animations disabled if the system asks"]
- Forced colours: toggle selected state and focus ring use system colours as in C2; borders stay (never rely on background only).

## Accessibility Contract (testable in Phase 5)

- Text contrast AA everywhere (values above); non-text contrast 3:1 for control borders and focus.
- One `h1` per page; headings in order; `lang="fr"`; landmarks `header`, `nav`, `main`, `footer`.
- Level toggle: `fieldset` + `legend`, native radios; one level in the accessibility tree at a time; announcement via `role="status"`.
- All targets ≥ 44 px (48 px at Aîné) except inline terms in running text.
- Colour is never the only carrier: theme names are written, statut is text, badge is text with a dashed border, selected toggle has a dot and an inverted fill.
- Keyboard: full tab order, popover openable with Enter/Space, Esc closes.
- Reflow at 320 CSS px and 160 % text without horizontal scroll or clipping.
- `prefers-reduced-motion` respected by having no motion; `forced-colors` handled.
- Manual checklist for Phase 5 (not automatable here): VoiceOver, NVDA, JAWS reading of inline popovers.
